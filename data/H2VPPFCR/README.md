# H2VPPFCR — hydrogen-VPP FCR co-sizing case study

Reproducibility bundle for the paper:

> **Market-driven co-sizing of a hybrid power–hydrogen virtual power plant for
> energy and frequency reserve markets**, E. F. Alvarez, J. F. Gutierrez-Guerra,
> A. Ramos.

It co-optimises the sizing and the full-year hourly operation of a
wind–battery–electrolyser–tank(+compressor) plant behind one grid connection in
Swedish bidding zone **SE3**, bidding into the Nordic **FCR-N** and **FCR-D**
markets, using **real 2025** prices, wind, and measured activation duties. Every
number in the paper regenerates from the inputs here against the model version in
this release.

This is the paper case; `../H2VPP/` is a separate one-second solve-test seed, not
this study.

## Layout

```
H2VPPFCR/
  build_case.py                     # source of truth: assembles the case from the 2025 series
  build_prices_year.py              # day-ahead + FCR capacity price series -> inputs/real_data/year
  build_wind_se3_year.py            # ERA5 -> site wind capacity factor
  build_kappa_year.py              # Nordic frequency record -> FCR activation duties
  run_resp_campaign_parallel.py     # runs the 14 headline cases + the S6-S9 spokes (carries the flags)
  run_resp_figs_parallel.py         # figure-data runs (heatmap, erosion, cycling)
  run_p4_spokes_parallel.py         # extra robustness spokes
  comillas_combined_campaign_eur.cmd  comillas_fcr_erosion_eur.cmd  comillas_heatmap_eur.cmd
  data_sources.md  data_sources.bib # provenance for every techno-economic and market figure
  inputs/
    real_data/year/                 # the 2025 SE3 series build_case.py consumes (8736 hourly rows each)
      spot_se3.csv                  # datetime_utc, price_eur_mwh          (ENTSO-E Transparency, SE3 day-ahead)
      fcr_se.csv                    # datetime_utc, fcr_n/fcr_d_up/fcr_d_down_eur_mw  (Svenska kraftnat)
      wind_se3.csv                  # datetime_utc, cf                     (ERA5 reanalysis, coastal SE3)
      fcr_activation_2025.csv       # hour, FCRD_Up/Down, FCRN_Up/Down     (measured Nordic frequency, 3-min -> hourly duty)
    H2VPPFCR/                       # frozen generated base case (ready to run): oM_Data_*.csv
```

## Data sources

`data_sources.md` lists every techno-economic and market figure with its source
(DEA Technology Data 2024/2030, NREL ATB 2024, Svenska kraftnat, ENTSO-E, the
RISE HiWhyV hydrogen valley, and the hydrogen offtake benchmarks). The raw
upstream files the derived series come from — the ERA5 NetCDF and the full Nordic
frequency record — are **not** re-hosted here; they are obtained from the public
sources cited in the paper (ENTSO-E Transparency Platform, Svenska kraftnat, and
ECMWF ERA5). The four CSVs under `inputs/real_data/year/` are the derived series
the model actually reads.

## Regenerate the case

Regenerate the input CSVs (only needed if you re-fetch the upstream data):

```bash
python build_prices_year.py      # -> inputs/real_data/year/{spot_se3,fcr_se}.csv
python build_wind_se3_year.py    # -> inputs/real_data/year/wind_se3.csv
python build_kappa_year.py       # -> inputs/real_data/year/fcr_activation_2025.csv
```

Rebuild the model case from the series (full year = 8736 hours = 52 weeks):

```bash
H2VPP_HORIZON=year H2VPP_CURRENCY=EUR python build_case.py   # writes inputs/H2VPPFCR/oM_Data_*.csv
```

## Run the campaign

The paper's fourteen headline cases (A1, A2, A3, B0, B1, B2, C2, D1, D2, S1–S5)
and the four spokes (S6–S9) are defined in `run_resp_campaign_parallel.py`. The
reserve-deliverability flags matter — a run without them silently drops the
ramp gate and the endurance limits — so the campaign always sets:

```
PRESSURE_NODES=1 LP=1 AEL_N=6 PEM_N=6
COMPRESSOR_NAMEPLATE_KG=1000 WIND_MAX_POWER_KW=60000 LINE_TTC_KW=60000 ELE_BUY_CAP_KW=60000
ELE_FCRD_RAMPGATE=1 AEL_FCRD_RAMP_PER_S=0.02 PEM_FCRD_RAMP_PER_S=0.10
H2VPP_HORIZON=year H2VPP_CURRENCY=EUR MONEY_BASE=1000
```

Each case is one env change on top of this common block (e.g. `B1` = FCR-N only,
`S1` = degradation off via `DEG_SCALE=0`, `S6` = `CYCLING_SCALE=0`, `S7` =
`BYPRODUCT_SCALE=0`, `S8` = `WIND_MODE=ppa`, `S9` = `CONNECTION_SCALE=0`). The
headline cases are solved as the **linear relaxation** (`LP=1`) with **Gurobi**
(barrier, `BarHomogeneous=1`, `NumericFocus=3`); the full-year instance is 3.2–5.0
million rows and solves in tens of minutes each.

## Notes

- **Currency.** Regulatory charges are set in SEK; the case is emitted and the
  paper reports results in EUR at the ECB 2025 average 11.0671 SEK/EUR (USD costs
  at EUR/USD 1.1306). See `data_sources.md`.
- **Reproducibility.** The frozen `inputs/H2VPPFCR/` case was generated by
  `build_case.py` at the paper's model commit; regenerate it against this release
  tag before relying on byte-identity, since the builder evolves with the model.
- Build outputs (`oM_Result_*`, `*.lp`, `*.log`, `*.sol`) are git-ignored.
